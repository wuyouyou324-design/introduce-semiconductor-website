# Introduce Semiconductor Website

半導體與邏輯閘入門互動式學習網站。

## 目標
提供清晰、視覺化且具互動性的半導體製造流程與邏輯閘原理介紹，協助學習者快速上手半導體與電腦科學基礎。

## 專案結構
- `src/app/`: 應用程式核心與路由設定
- `src/components/layout/`: 佈局元件 (Header, Footer, Sidebar 等)
- `src/components/ui/`: 通用 UI 元件
- `src/features/`: 各功能模組 (learning, logic-gates, manufacturing, search)
- `src/pages/`: 頁面元件
- `src/data/`: 靜態資料與模型
- `src/styles/`: 全域樣式
- `src/types/`: TypeScript 型別定義
- `tests/`: 單元測試與整合測試

## 開發與執行指令

### 安裝依賴
```bash
npm install
```

### 啟動開發伺服器
```bash
npm run dev
```

### 建置生產版本
```bash
npm run build
```

### 執行測試
```bash
npm test
```
