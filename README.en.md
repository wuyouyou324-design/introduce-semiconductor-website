# Introduce Semiconductor Website

An interactive science learning website introducing semiconductors and logic gates.

[中文繁體](./README.md) | English

## Objective
Provide clear, visual, and interactive introductions to semiconductor manufacturing processes and logic gate principles, helping learners quickly grasp the basics of semiconductors and computer science.

## Project Structure
- `src/app/`: Application core and routing configuration
- `src/components/layout/`: Layout components (Header, Footer, Sidebar, etc.)
- `src/components/ui/`: General UI components
- `src/features/`: Feature modules (learning, logic-gates, manufacturing, search)
- `src/pages/`: Page components
- `src/data/`: Static data, models, and i18n translations (`translations.ts`)
- `src/styles/`: Global styles
- `src/types/`: TypeScript type definitions
- `tests/`: Unit and integration tests

## Development & Execution Commands

### Install Dependencies
```bash
npm install
```

### Start Development Server
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```

### Run Tests
```bash
npm test
```
