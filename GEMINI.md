# Introduce Semiconductor Website - Project Guidelines

## Tech Stack
- **Framework:** React 19 + TypeScript + Vite
- **Styling:** Vanilla CSS / CSS Modules
- **Testing:** Vitest + React Testing Library

## Architectural Conventions
- Feature-based architecture under `src/features/`.
- Clear separation between UI components (`src/components/ui`), layouts (`src/components/layout`), and pages (`src/pages/`).
- Strict TypeScript type safety across all files.
